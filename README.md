# Orange Env 🍊

A portable terminal environment setup script

## Features
- zsh setup
- neovim
- tmux
- cross-platform (apt + brew)
- Docker support

# Install 
## test like a stranger, be safe! (seriously). 
```bash
git clone https://github.com/cipherpig/orange-env.git
cd orange-env
chmod +x setup.sh
./setup.sh
```
